# 历史汉语音韵数据资源清单

> 调研日期：2026-10-27。范围是公开网络上与历史汉语音系、韵书/韵图、学者拟音、汉字读音映射及验证语料相关的资源。这里的“可信度”评估的是来源可追溯性、文献依据和可验证性，不代表某一拟音方案在学界绝对正确。
>
> **重要边界**：韵书原始记录、音韵地位、学者重构、现代方言读音、古典文本语料不是同一类数据。某个仓库的代码许可证不自动覆盖其数据、扫描图、转录或衍生重构；未明确授权的资源只登记来源，不直接复制进项目。

## 可信度评分口径

- **高**：来源/版本明确，可定位原始文献或维护仓库；字段含义清楚；存在校验、文献或可复现规则。
- **中高**：来源较清楚，但自动推导、校勘范围、版本覆盖或部分字段还需要抽查。
- **中**：可用于探索或比较，但许可、数据抽取、代表性或错误率仍有重要不确定性。
- **低/实验性**：来源链断裂、无法确认版本，或尚未完成逐条验证。
- 该分数不是学术方案优劣排名。高本汉、王力、郑张尚芳、白一平—沙加尔等体系之间可能采用不同理论假设；方案间不一致不自动意味着某一方错误。

## 每条导入记录必须保留的来源字段

建议统一字段：`dataset_id`、`dataset_version`、`upstream_url`、`upstream_commit_or_blob_sha`、`license`、`citation`、`historical_period`、`system_id`、`record_type`（原始条目/音韵地位/转写/拟音/现代读音/文本语料）、`source_entry_id`、`character`、`reading_variant_id`、`phonological_position`、`transcription`、`derivation_rule_version`、`confidence`、`review_status`。

**不要把 `available` 当作“有数据”的唯一标记**：一条记录可以有可靠的音韵地位而没有 IPA；也可以有研究者转写但不适合直接 TTS。建议分别表达 `has_record`、`has_reconstruction`、`is_synthesizable`、`license_allows_redistribution`。

## 本次调研的边界

本清单是截至 2026-10-27 的可检索公开资源调查，不宣称穷尽互联网全部数据。优先覆盖能被项目实际使用、可追溯和有明确来源的资源。下载入口可用、代码开源、数据可查询、数据可再分发是四件不同的事；授权状态不清楚时，默认只记录来源与元数据，不把原始数据复制进公开仓库。
